# Marketplace Screenshot Plan

Canvas: 1280x800 PNG for Chrome Web Store screenshots.

## Shot List

1. `01-all-tabs-overview-50-tabs.png` - main value proposition: 50 open tabs summarized in one calm workspace.
2. `02-search-open-tabs-github.png` - search inside open tabs.
3. `03-domain-groups.png` - domain grouping for scanning repeated work contexts.
4. `04-window-groups.png` - window grouping for multi-project browser sessions.
5. `05-duplicate-cleanup.png` - duplicate tab detection and cleanup.
6. `06-settings-protection-theme.png` - settings, protection rules, theme and language controls.
7. `07-accent-palette.png` - eastern accent palette and visual customization.
8. `08-web-search-mode.png` - switch from tab search to browser web search.

## Suggested Store Order

Use shots 1-5 as the main Chrome/Edge carousel because they explain the core tab-management value without reading copy. Use shots 6-8 after the core workflow to show polish, customization, and extra search behavior.

## Layout Notes

- Keep the product UI as the full screenshot; do not add marketing frames around it.
- If adding captions later, place one short line at the top-left safe area outside the central panel or use store-provided caption fields.
- Avoid cropping the right-side settings sheet in shot 6; it is the clearest feature-detail screenshot.
